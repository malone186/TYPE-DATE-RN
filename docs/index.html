1회원가입이 없습니다

앱은 회원가입 절차가 없습니다. 게임 진행을 위해 이름을 입력할 수 있지만 이 값은 게임 속 호칭으로 기기에만 저장됩니다. 이메일은 1:1 문의에서 답변을 원할 때 이용자가 선택해 입력합니다.

1:1 문의 기능에 한해 가입 없이 자동으로 만들어지는 익명 계정을 사용합니다. 문의에는 익명 계정 ID와 앱이 만든 기기 구분값이 연결될 수 있으므로, 이를 "절대 연결되지 않는 식별 불가능 정보"라고 단정하지 않습니다.

2수집하는 정보

2-1. 이용 통계 (자동 수집)

앱 개선을 위해 아래 이용 기록을 수집합니다. 분석 이벤트에는 사용자가 게임에 입력한 이름이나 문의 본문을 넣지 않지만, 앱이 만든 기기 구분값으로 기록을 연결할 수 있습니다.

항목내용

광고 관련SDK가 전면 광고를 열었다고 알린 기록, 구매·복원·테스트 처리 구분
오류 기록오류가 발생한 화면, 오류 메시지(최대 200자), 오류 종류

기기 구분값에 대하여 — 앱이 자체적으로 만든 무작위 UUID이며 광고 식별자(ADID/IDFA)나 기기 고유번호를 직접 읽어 만든 값은 아닙니다. 앱 저장소가 초기화되면 새 값이 생성되지만, 운영 서버에 이미 저장된 과거 기록이 자동으로 삭제되는 것은 아닙니다. 문의 기록에서는 이 값과 익명 계정 ID·선택 입력 이메일이 함께 저장될 수 있습니다.

2-3. 수집하지 않는 정보

앱은 아래 정보를 게임 기능을 위해 직접 요청하지 않습니다. 다만 광고·결제 SDK 및 운영 플랫폼이 서비스 제공 과정에서 처리하는 항목은 아래 5절과 스토어의 고지를 함께 확인해야 합니다.

  • 이름, 생년월일, 성별, 연락처 등 신원 정보
  • 위치 정보 (GPS·네트워크 위치 모두)
  • 연락처, 사진, 파일 등 기기 내 데이터
  • 기기 고유번호(IMEI 등)
  • 통신사, 기기 모델명 등 단말기 정보

2-4. 기기 안에만 저장되는 정보

아래 정보는 이용자의 기기 안에만 저장되며 서버로 전송되지 않습니다.

  • 앱에서 입력한 이름 (게임 속 호칭으로만 사용)
  • 회차 진행 상황과 결과 기록
  • 설정값 (테마, 글자 크기, 소리 크기)
  • 서버 검증을 거친 광고 제거 entitlement의 로컬 캐시

앱을 삭제하면 함께 삭제되며, 개발자는 이 정보에 접근할 수 없습니다.

3수집한 정보의 이용 목적

  • 어느 화면·회차에서 이용자가 이탈하는지 파악하여 콘텐츠를 개선하기 위해
  • 선택지 응답 분포를 확인하여 게임 밸런스를 조정하기 위해
  • 앱 오류를 발견하고 수정하기 위해
  • 1:1 문의에 답변하기 위해

분석 이벤트는 앱 개선·오류 확인 목적에 사용하며, 광고 SDK가 처리하는 광고 요청·성과 측정은 해당 SDK의 정책과 동의 상태에 따릅니다. 앱의 분석 이벤트를 맞춤 광고용 프로필로 사용하지 않습니다.

6이용자의 권리

이용자는 언제든지 아래 권리를 행사하실 수 있습니다.

  • 수집 거부·동의 철회 — 광고 동의가 필요한 경우 SDK가 제공하는 설정 화면에서 변경할 수 있습니다. 네트워크 차단은 통계 전송을 막을 수 있지만 서버에 이미 보관된 정보의 삭제 요청을 대신하지 않습니다.
  • 열람·삭제 요청 — 앱 내 설정 → 1:1 문의 또는 아래 연락처로 요청하실 수 있습니다. 요청 식별을 위해 문의에 사용한 이메일, 기기 구분값 또는 기타 안전한 확인 정보를 요청할 수 있습니다. 처리 담당·기한은 운영자가 확정해야 합니다.
  • 앱 삭제 — 앱 삭제는 기기에 저장된 정보의 삭제를 뜻하며, 서버에 이미 저장된 통계·문의·구매 원장은 별도 요청과 운영 절차가 필요합니다. OS 백업으로 일부 설정이 복원될 수 있으므로 즉시·완전 삭제를 보장하지 않습니다.

7만 14세 미만 아동

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다. 아동의 정보가 수집된 사실을 알게 된 경우 확인 후 관련 법령과 운영 절차에 따라 삭제 요청을 처리합니다.

8안전성 확보 조치

  • 모든 통신은 HTTPS로 암호화되어 전송됩니다.
  • 데이터베이스에 행 수준 보안(RLS) 정책을 적용하여, 이용자는 본인의 문의만 조회할 수 있고 타인의 기록에는 접근할 수 없습니다.
  • 통계 원본 데이터는 사전에 등록된 관리자 계정만 조회할 수 있습니다.
  • 앱에 포함된 접근 키로는 데이터를 기록만 할 수 있고 조회는 불가능하도록 제한하고 있습니다.
